# ClipKeep

Gboardのクリップボードの代わりに使う、**消えない**クリップボード履歴アプリ。

- 履歴は自動で消えない（既定1000件、設定で無制限まで変更可）
- 定型文をタブで分類して編集できる
- 定型文は件数制限の対象外で、絶対に自動削除されない
- 常駐通知から履歴を開ける／直前のコピーをワンタップで戻せる
- 完全オフライン。インターネット権限を一切持たないので、履歴が外に出ることはない

---

## 最初に知っておくこと（重要）

**Android 10以降、アプリがバックグラウンドでクリップボードを読むことをOSが禁止しています。**
読み取りが許されるのは次の2つだけです。

1. 既定のキーボード（IME）になっているアプリ
2. いま画面のフォーカスを持っているアプリ

Gboardを使い続けたい以上、1は使えません。そこでClipKeepは**捕捉の入口を4つ**用意し、
どれかが必ず通るようにしています。

| 入口 | 確実性 | 使い方 |
|---|---|---|
| 文字選択メニュー | ◎ 常に動く | 文字を長押し → メニューの「ClipKeepに保存」 |
| 常駐通知のボタン | ◎ 常に動く | 通知の「今のコピーを保存」をタップ |
| クイック設定タイル | ◎ 常に動く | 通知シェードのタイル「コピーを保存」をタップ |
| アクセシビリティ監視 | △ 端末依存 | 設定でオンにすると、コピー操作を自動記録しようと試みる |

アクセシビリティ監視は端末・OSバージョン・メーカーROMによって**OSに拒否される場合があります**。
拒否されても他の入口は動くので、アプリが使えなくなることはありません。
まず監視をオンにして数日試し、自動で貯まらないようなら文字選択メニュー方式に切り替えるのがおすすめです。

なお Android 12 以降では、クリップボードを読むたびに
「ClipKeep がクリップボードからテキストを貼り付けました」というトーストが出ます。これはOSの仕様で消せません。

## ビルド方法

APKは2通りの作り方があります。**Android Studioを入れたくないならBがおすすめです。**

### A. Android Studioでビルドする

1. [Android Studio](https://developer.android.com/studio) をインストール
2. `File → Open` でこの `ClipKeep` フォルダを開く
3. 初回は依存関係のダウンロードで数分かかります
4. `Run` ボタン（緑の▶）でUSB接続した端末にインストール
   - APKだけ欲しい場合は `Build → Build Bundle(s) / APK(s) → Build APK(s)`

> このフォルダにはGradle Wrapperのバイナリ（`gradlew` / `gradle-wrapper.jar`）が含まれていません。
> Android Studioは開いたときに自動で生成します。もしコマンドラインで叩きたい場合は、
> 一度 `gradle wrapper --gradle-version 8.10.2` を実行してください。

### B. GitHub Actionsでビルドする（PCに何も入れない）

1. [github.com](https://github.com) でアカウントを作る
2. 新しいリポジトリを作る（Privateで構いません）
3. この `ClipKeep` フォルダの中身をまるごとアップロードする
   （リポジトリ画面の `Add file → Upload files` にドラッグ＆ドロップ）
4. `Actions` タブを開く → `Build APK` → `Run workflow`
5. 数分待つと、実行結果の下に `ClipKeep-debug-apk` というzipが出るのでダウンロード
6. 中の `app-debug.apk` をスマホに転送してインストール

`.github/workflows/build.yml` が自動ビルドの設定です。触る必要はありません。

## インストール後のセットアップ

1. APKをタップしてインストール（「提供元不明のアプリ」の許可を求められたら許可）
2. アプリを開き、通知の権限を許可する → 常駐通知が出ます
3. `設定` タブ →「アクセシビリティ監視」の**オンにする** → 端末の設定画面で ClipKeep を選んで有効化
4. （任意）通知シェードのタイル編集から「コピーを保存」を追加しておくと便利

## 使い方

**記録する**

- 文字を長押しして出るメニューから「ClipKeepに保存」（一番確実）
- 何かをコピーしたあと、通知の「今のコピーを保存」をタップ
- アクセシビリティ監視がオンで動く端末なら、コピーするだけで自動記録

**貼り付ける**

- 通知をタップ → 履歴一覧 → 使いたい行をタップするとクリップボードに入るので、あとは普通に貼り付け
- 直前の1件は通知の「直前をコピー」でワンタップ

**定型文にする**

- 履歴の行の右端 `⋮` →「定型文にする」→ タブを選ぶ
- または `定型文` タブの右下 `＋` から直接追加
- タブの追加はタブ列の一番右の `＋`、名前変更・削除は選択中タブの鉛筆アイコン
- タブを消しても中の定型文は消えず「未分類」に移ります

---

## 設定でできること

| 項目 | 説明 |
|---|---|
| 履歴の保持件数 | 既定1000。`0` を入れると無制限 |
| 常駐通知 | オフにすると通知は消えるが、通知経由の保存も使えなくなる |
| 履歴をすべて削除 | 定型文は残る |

## 補足

- Google Play への公開は想定していません（アクセシビリティ権限の審査が厳しいため）。自分用のサイドロード前提です。
- ネットワーク権限を持たないので、履歴が端末外に出ることは仕組み上ありません。
- 画像やファイルのクリップボードには未対応（テキストのみ）。
